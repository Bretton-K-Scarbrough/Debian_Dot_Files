# Debian_Dot_Files

Steps to take after a fresh install of Debian

- If you set a root password in Debian when initially installing, it will not install sudo automatically. So don't set a password for sudo when initially installing.
1. Install git via apt `sudo apt update` followed by `sudo apt install git`
2. Git clone the repo: `git clone https://github.com/Bretton-K-Scarbrough/Debian_Dot_Files.git`
